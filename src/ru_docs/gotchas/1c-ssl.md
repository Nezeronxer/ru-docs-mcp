# 1С: Библиотека стандартных подсистем 3.2

## Безопасное хранилище: привилегированный режим включает вызывающий код сам
`ОбщегоНазначения.ЗаписатьДанныеВБезопасноеХранилище` и `УдалитьДанныеИзБезопасногоХранилища` режим не включают:
оборачивайте вызов в `УстановитьПривилегированныйРежим(Истина)` ... `(Ложь)`. `Владелец` - ссылка или строка до
128 символов, `Ключ` - идентификатор (по умолчанию `"Пароль"`). `Данные = Неопределено` удаляет все данные, а не
один ключ: для ключа есть `УдалитьДанныеИзБезопасногоХранилища`. В `ПередУдалением` данные из хранилища удаляют
и при удалении объекта обменом данными.
Источник: https://github.com/1c-syntax/ssl_3_2/blob/master/src/cf/CommonModules/ОбщегоНазначения/Ext/Module.bsl
Проверено: 2026-10-05

## ЗначенияРеквизитовОбъекта: по умолчанию читает без учёта прав и кидает исключение
`ВыбратьРазрешенные = Ложь` (по умолчанию): при отсутствии прав на таблицу или реквизит - исключение.
`Истина` - с учётом прав, при ограничении на уровне записей все реквизиты `Неопределено`. Чтобы читать
независимо от прав, заранее включите привилегированный режим. Несуществующий реквизит - исключение "Поле
объекта не существует", пустая или битая ссылка - `Неопределено` в значениях. В
`ЗначенияРеквизитовОбъектов` (по массиву ссылок) объекты, недоступные по правам, пропадают из результата.
Источник: https://github.com/1c-syntax/ssl_3_2/blob/master/src/cf/CommonModules/ОбщегоНазначения/Ext/Module.bsl
Проверено: 2026-10-05

## Необязательная подсистема: сначала ПодсистемаСуществует, потом ОбщийМодуль, и свои функции для клиента
`ОбщегоНазначения.ОбщийМодуль(Имя)` вызывают только внутри условия
`ОбщегоНазначения.ПодсистемаСуществует("СтандартныеПодсистемы.<Имя>")`. Полное имя пишется без слова
"Подсистема." и с учётом регистра. В клиентском коде нужны `ОбщегоНазначенияКлиент.ПодсистемаСуществует`
и `ОбщегоНазначенияКлиент.ОбщийМодуль`; серверный `ОбщийМодуль` принимает и модули менеджеров
(`Обработки.ПолнотекстовыйПоиск`).
Источник: https://github.com/1c-syntax/ssl_3_2/blob/master/src/cf/CommonModules/ОбщегоНазначения/Ext/Module.bsl
Проверено: 2026-10-05

## Фоновая процедура получает (Параметры, АдресРезультата) и отдаёт результат через временное хранилище
Процедура для `ДлительныеОперации.ВыполнитьВФоне` (в её описании рекомендованы `ВыполнитьФункцию` и `ВыполнитьПроцедуру`) должна
иметь 2 или 3 формальных параметра: `Параметры`, `АдресРезультата` (обязателен), опционально `АдресДополнительногоРезультата`.
Функцию оборачивают в процедуру. Если `ИдентификаторФормы = Неопределено`, хранилище чистите сами. В файловой ИБ во внешнем
соединении фоновых заданий нет, при активных заданиях новое ждёт в очереди. `ОтменитьВыполнениеЗадания` откатывает только
последнюю открытую транзакцию: для отмены "всё или ничего" пишите данные одной транзакцией.
Источник: https://github.com/1c-syntax/ssl_3_2/blob/master/src/cf/CommonModules/ДлительныеОперации/Ext/Module.bsl
Проверено: 2026-10-05

## Скачивание файла не бросает исключение: смотрите Статус, а временное хранилище чистите сами
`ПолучениеФайловИзИнтернета.СкачатьФайлНаСервере` и `СкачатьФайлВоВременноеХранилище` возвращают
структуру с `Статус` (Булево), `СообщениеОбОшибке` и `КодСостояния` (только при ошибке); `Путь` валиден
лишь при `Статус = Истина`. `ЗаписыватьОшибку = Истина` по умолчанию пишет ошибку в журнал регистрации.
После `СкачатьФайлВоВременноеХранилище` вызывайте `УдалитьИзВременногоХранилища`, иначе файл останется в
памяти сервера до конца сеанса.
Источник: https://github.com/1c-syntax/ssl_3_2/blob/master/src/cf/CommonModules/ПолучениеФайловИзИнтернета/Ext/Module.bsl
Проверено: 2026-10-05

## Для HTTP-вызовов в профиле безопасности нужно разрешение на интернет-ресурс и применение запроса
`РазрешениеНаИспользованиеИнтернетРесурса(Протокол, Адрес, Порт)`: протокол из
`IMAP, POP3, SMTP, HTTP, HTTPS, FTP, FTPS, WS, WSS`, адрес без протокола. `ЗапросНаИспользованиеВнешнихРесурсов` только
создаёт запрос: применить его нужно `РаботаВБезопасномРежимеКлиент.ПрименитьЗапросыНаИспользованиеВнешнихРесурсов`.
`РежимЗамещения` по умолчанию `Истина` и добавляет очистку всех разрешений, ранее запрошенных тем же владельцем:
передавайте полный набор разрешений владельца.
Источник: https://github.com/1c-syntax/ssl_3_2/blob/master/src/cf/CommonModules/РаботаВБезопасномРежиме/Ext/Module.bsl
Проверено: 2026-10-05
