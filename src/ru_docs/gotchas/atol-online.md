# АТОЛ Онлайн

## Токен живёт 24 часа: перезапрашивать только по ошибке ExpiredToken
Токен из `getToken` действует 24 часа. Документ рекомендует брать новый только после ошибки
`ExpiredToken` (код 11, HTTP 401), а не на каждый чек. Токен передают в заголовке `Token: <token>`,
query-параметр `?token=` допустим, только если заголовок передать технически нельзя.
Источник: https://online.atol.ru/files/API_atol_online_v4.pdf
Проверено: 2026-10-05

## Повторная отправка с тем же external_id не создаёт второй чек
`external_id` (до 128 символов) должен быть уникален в пределах группы ККТ и нужен для повторов при
обрыве связи. Если он уже известен, сервис вернёт ранее выданный `uuid`; ошибка
`IncomingExternalIdAlreadyExists` (код 33, HTTP 400, тип System/Wait) означает "документ уже есть", её
нельзя считать провалом чека. Новый `external_id` на повтор даст дубль чека.
Источник: https://online.atol.ru/files/API_atol_online_v4.pdf
Проверено: 2026-10-05

## Результат чека: callback, затем опрос GET report/uuid не чаще 1 запроса в секунду на ККТ
После `done` или `fail` сервис шлёт POST на `callback_url`. Если за 300 секунд ничего не пришло,
опрашивайте `GET .../<group_code>/report/<uuid>`. Лимит: один запрос в секунду на одну ККТ группы, повтор
после системной ошибки не раньше чем через секунду. GET работает только для чеков не старше 32 суток.
Ответ `StateCheckNotFound` (код 34, HTTP 200, статус wait) значит "ещё не обработан": опрашивать позже,
чек повторно не слать.
Источник: https://online.atol.ru/files/API_atol_online_v4.pdf
Проверено: 2026-10-05

## Суммы в рублях числом с 2 знаками, а не в копейках; sum не пересчитывается в скидку
`price` и `sum` позиций, `payments[].sum`, `total` передаются в рублях (не более 2 знаков после запятой,
не более 8 в целой части; максимум 42 949 672.95). `quantity`: не более 3 знаков после запятой. `total`
можно округлить не более чем на 99 копеек; фактическая сумма считается как сумма `sum` позиций.
Автоскидка при `sum` != `price*quantity` кассами больше не поддерживается: рассчитывайте `sum` сами.
Источник: https://online.atol.ru/files/API_atol_online_v4.pdf
Проверено: 2026-10-05

## payment_method по умолчанию full_prepayment, а не full_payment
Если не передать `payment_method`, в позицию уйдёт `full_prepayment` (предоплата 100%), а
`payment_object` по умолчанию `commodity`. Для обычной оплаты в момент передачи товара явно ставьте
`payment_method: "full_payment"` и нужный `payment_object` (услуга, работа и т.д.).
Источник: https://online.atol.ru/files/API_atol_online_v4.pdf
Проверено: 2026-10-05

## v4 это ФФД 1.05, для ФФД 1.2 нужен v5
Версия API входит в URL: `/possystem/<api_version>/...`. По документу `v4` регистрирует чеки ФФД 1.05,
`v5` - ФФД 1.2. Если группа ККТ не поддерживает протокол, придёт `NotSupportedGroupCodeForProtocol` (код
21, HTTP 401) с указанием слать на `v5`. Этот документ описывает только v4: поля ФФД 1.2 по ней не
проверять.
Источник: https://online.atol.ru/files/API_atol_online_v4.pdf
Проверено: 2026-10-05
