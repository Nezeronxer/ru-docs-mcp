# DaData

## У стандартизации (clean) свой хост и заголовок X-Secret, из браузера её вызывать нельзя
Подсказки (`suggestions.dadata.ru`) работают с одним `Authorization: Token <API_KEY>`.
Стандартизация (`cleaner.dadata.ru/api/v1/clean/...`) требует ещё `X-Secret: <SECRET_KEY>`
и не поддерживает вызов из браузерного JS: секретный ключ утечёт. Вызывайте её только с сервера.
Источник: https://dadata.ru/api/clean/address/
Проверено: 2026-10-05

## Район города, метро и часовой пояс подсказки отдают только после выбора адреса (count=1)
В списке подсказок нет района города; площадь квартиры, метро и часовой пояс есть только на тарифе «Максимальный».
И то и другое приходит после выбора адреса пользователем: повторите запрос с `"count": 1`, а в `query` передайте
`unrestricted_value` выбранной подсказки (произвольный текст не подойдёт).
Источник: https://dadata.ru/api/suggest/address/
Проверено: 2026-10-05

## Clean принимает один адрес за запрос и стоит 20 копеек за запись; подсказки для автообработки не годятся
Тело - JSON-массив, но разрешён только один адрес за запрос; цена - 20 копеек за запись.
Подсказки (`suggest`) для автоматической обработки адресов не предназначены: они лишь предлагают варианты
и не гарантируют верный. Автоматический разбор базы - только через стандартизацию (`clean`).
Источник: https://dadata.ru/api/clean/address/
Проверено: 2026-10-05

## Подсказки бесплатны до 10 000 запросов в день суммарно, потом 403 до конца дня
Лимит 10 000 в день общий для всех видов подсказок (адреса, ФИО, организации, банки, email). После него подсказки
не работают до начала нового дня: сервис отвечает `403` - тем же кодом, что и на несуществующий ключ
или неподтверждённую почту.
Источник: https://dadata.ru/api/suggest/address/
Проверено: 2026-10-05

## Частота: 30 запросов/с у подсказок, 20/с у clean и не больше 60 новых соединений в минуту, иначе 429
Лимиты считаются с одного IP: подсказки - до 30 запросов в секунду, стандартизация - до 20;
новых соединений - не больше 60 в минуту. Превышение даёт `429`. Держите один HTTP-клиент с keep-alive
вместо нового соединения на каждый запрос.
Источник: https://dadata.ru/api/suggest/address/
Проверено: 2026-10-05

## ИНН компании с филиалами вернёт несколько объектов: головную выбирают через branch_type=MAIN
Метод `findById/party` по ИНН возвращает и головную организацию, и филиалы. Для головной добавьте
`"branch_type": "MAIN"`, для конкретного филиала - `kpp` или `ИНН/КПП` через слеш в `query`.
У 25% компаний КПП филиалов налоговая не сообщает - такие филиалы этим методом не найти.
Источник: https://dadata.ru/api/find-party/
Проверено: 2026-10-05
