# Т-Банк интернет-эквайринг

## Где читать полную документацию
Сырые страницы developer.tbank.ru в индекс не входят: сайт подписан корнем Минцифры (Russian Trusted
Root CA), ему ru-docs намеренно не доверяет. Полная документация - Context7
`/websites/developer_tbank_ru_eacq` или https://developer.tbank.ru/eacq/intro в браузере.
Источник: https://developer.tbank.ru/eacq/intro
Проверено: 2026-10-04

## Token: только корневые скалярные поля + Password, сортировка по ключу
Подпись запроса: берёте пары ключ-значение **только корневого уровня**, без `Token` и без вложенных
объектов (`Receipt`, `DATA` и т.п. не участвуют), добавляете `{"Password": <пароль терминала>}`,
сортируете по ключу, склеиваете **только значения** в одну строку и берёте SHA-256 (hex).
Пример из доков: `19200Подарочная карта на 1000 рублей0000011111111111111MerchantTerminalKey`
→ `72dd466f...426db2`. Частая ошибка - включить Receipt или сортировать по значению.
Источник: https://developer.tbank.ru/eacq/intro/developer/token
Проверено: 2026-10-04

## Нотификации: проверять Token тем же алгоритмом, булевы - строкой "true"/"false"
Входящее уведомление подписано так же: все корневые поля кроме `Token` и вложенных объектов +
Password, сортировка, склейка значений, SHA-256. `Success: true` в склейке превращается в `true`
(строчными), а не `True` и не `1` - в Python не используйте `str(bool)`. Без проверки Token
любой может прислать «CONFIRMED».
Источник: https://developer.tbank.ru/eacq/intro/developer/notification
Проверено: 2026-10-04

## Amount - целое число в копейках
`"Amount": 19200` = 192 рубля. Для чека: `Price` и `Amount` позиций тоже в копейках, а сумма всех
`Items[].Amount` должна быть равна `Amount` платежа, иначе Init вернёт ошибку.
Источник: https://developer.tbank.ru/eacq/api/init
Проверено: 2026-10-04

## Частичная отмена требует Receipt
`/v2/Cancel` с `Amount` меньше суммы платежа - частичная отмена; если терминал работает с чеками,
`Receipt` в этом запросе обязателен.
Источник: https://developer.tbank.ru/eacq/api/cancel
Проверено: 2026-10-04
